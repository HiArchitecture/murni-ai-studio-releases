## Murni AI Studio for Mac

Installers and updates for **Murni AI Studio**, the AI retouching app for architectural renders by
[Hi architecture detail](https://hiarchitecturedetail.com).

**[Download Murni AI Studio for Mac (Apple Silicon)](https://github.com/HiArchitecture/murni-ai-studio-releases/releases/latest/download/Murni-AI-Studio-arm64.dmg)**

- The app requires an **activation key**, sent by email after your purchase on
  [hiarchitecturedetail.com](https://hiarchitecturedetail.com). One key activates one computer at a time.
- Installation: open the `.dmg` and drag Murni AI Studio to Applications. On first launch, if macOS says the developer
  cannot be verified: System Settings › Privacy & Security › **Open Anyway**.
- Updates are installed from the app (Murni AI Studio › Check for Updates…). Every version published here is signed; the
  app refuses any version that is not.
- Help and questions: [hiarchitecturedetail.com](https://hiarchitecturedetail.com).

This repository only contains published versions; the source code is not public.
